# W4 本地验收与来源记录

实现入口：[W4 证据与来源](../../w4-evidence-provenance.md)。范围为 B11、C01–C03，保留 W2/W3 现有改动与历史材料。

最终结果以 `validation.json`、`source-manifest.json` 和 `latest-run.json` 指向的 `runs/.../receipts.json` 为准。每条命令保存执行时间、退出码及原日志；检查前后的源码摘要必须一致。`manifest.json` 逐文件绑定本目录证据。HEAD 是未提交工作区的基线，不是这批实现的完整版本标识。

目录与 `validation.date` 使用既定 W4 批次日期；收尾验收跨至新加坡 2026-10-18，实际执行时间以 UTC `generated_at` 和命令收据为准。

验证包括 lint / check / build、应用普通测试与覆盖率、151 项合约测试、W2/W3/W4 的实际本地 EVM/HTTP、14 项浏览器回归、确定性 Agent 评测和离线 Demo preflight。普通应用命令有两项 W4 EVM 测试按设计跳过；`test:w4` 单独执行它们，最终不得有跳过。浏览器使用明确记录的现有 Chromium revision 1243；先前默认 revision 1248 缺失的失败保留为初始日志，不算 UI 通过。

preflight 先执行合约编译/测试，再在全量应用测试中启用这两项真实 EVM 场景；该门继续要求全量测试零跳过。390px 验证包括 W4 面板的实际宽度、内部溢出、下载及展开的复核表单；旧主页面的全局桌面布局不在该窄屏通过声明内。

W4 新增实际 EVM 覆盖真实测试 token 的 EIP-3009 转账、签名与精确事件、错误网络/资产/金额、确认深度、付款重启/未知广播/重组、HTTP 交付失败和原付款免费恢复；实际 AgentDecisionLog 覆盖当前版本未注册拒绝、材料包与根绑定、规范回执及重组撤销确认。其他回归检查两个独立 OS 进程竞争、密文/密钥失败、会话权限、材料缺件、离线新进程复算、无效/过期 schema、行情异常、人工接管版本变化及浏览器/CLI 不重新签署付款。

`provider-runs/` 保留真实配置端点的连接/抽取尝试、公共来源与本地回归，成功和失败都有独立时间戳。DCSA 公共测试语料、许可、固定提交与 manifest 位于 `data/evaluation/w4/`；报告使用的 manifest 也按 corpus hash 保存。OFAC 原始公开 CSV 以 gzip 保存，并绑定来源响应、Last-Modified 与 SHA-256。没有为记录评测而打印私钥、API key、原签名或 `.env` 值。

真实端点的单证输出未被采用，来源命中不代表企业合规。17 个字段的确定性回退结果不能冒充模型质量；月均价格的持平基线不能冒充货物回收估值。未执行首次测试网锚定、真实付款、外部身份/法律控制、独立物理机器恢复、远端 CI、提交或推送。

历史失败和修复说明见 [attempts.md](attempts.md)。后续复验会新建 `runs/<timestamp>/`，不得覆盖旧命令收据或把未运行的检查标成通过。
