# W4 证据与来源设计

范围：B11、C01–C03。以 W2 资金候选、W3 独立身份与加密材料为基础；保留已有未提交工作和历史证据。

- B11：六类版本化证据（原始材料、估值、条款、审批、执行、付款），严格 canonical JSON、整数金额字符串、UTC 时间、显式 null、域隔离哈希；内容、私盐和引用保存在 W3 vault。授权下载的自包含包可由独立进程离线复算，公共投影仅含承诺。缺件、旧 schema、篡改、过期均明确失败。保留历史 anchor v1 验证，新叶子使用 v2 隐私投影；覆盖率/延迟/缺口与包含证明分别报告。
- C01：版本化研究校准说明、商品/品级/单位/地区/币种/现货期货基差和净回收扣减；缺失、旧观测、市场停盘、跨源冲突和极端变动要求人工复核。规则估值和参考价不能成为独立估值。年化使用到期与出资时点的实际剩余期限。
- C02：冻结样本 manifest、版本和标签隔离；真实 provider、确定性回归分别记录，输出错误分布、误放行/误拒绝、转人工、证据支持和版本漂移。无业务批准阈值或独立数据时保持人工复核。人工接管绑定输入、模型/政策版本和原因，旧审批不得覆盖新版本。
- C03：Live 在解锁/attestation 前独立读取链、资产代码、EIP-3009 签名/授权、规范成功回执、AuthorizationUsed 与精确 Transfer、确认深度。付款身份按 chain/asset/payer/nonce，不按可变签名。未知结算只读找回，不自动再次 settle；重启、重组、生成失败和重复取回可恢复。报告付款与融资账本隔离。

不自动启用锚定、广播测试网交易、部署、提交或推送。真实独立单证、法律/身份、估值和合规质量的未验条件保留；本地合成样本不冒充独立提供方验收。源主机丢失的独立机器演练属于 W5，W4 验证离线包在新进程中不依赖原服务。
