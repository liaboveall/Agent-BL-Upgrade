# W3 权利与控制设计

日期：2026-10-17。基线：`e3d926a`；范围：综合报告 B04–B10，受限本地 / 测试网研究候选。

## 架构与业务选择

沿用 W2 `RWAOfferingPoolV5` 的资金、份额和恢复语义，新增不可绕过的 `RightsController` 作为新池的唯一 owner / oracle。不扩展已经接近 EIP-170 上限的资金合约，不更改现有部署。控制器没有任意调用、换 gate、转移 pool ownership 或增设裸 executor 的出口。部署新实例时必须使用新的承诺式 Registry、固定 minter Token 和控制器资格 gate；旧实例不能靠配置宣称已具备 W3。

- **B04**：可信签发方的 EIP-712 凭证绑定稳定资产标识、加盐文件承诺、独立 holder、修订、有效期和 nonce。共享身份 Hub 在受控 Registry 间永久保留同一资产槽位；更名、修订、作废不会释放去重键。质押由 holder 直接提交或签署，明确绑定 pool 和完整条款哈希。旧部署资产先以人工核对的别名清单导入 Hub，再启用新发行。全球防重复、真实承运人身份及法律控制另待独立证明。
- **B05**：发行前承诺处置政策。违约 / 清算损失结清须有通知期、可提出争议、独立处置审核及回收 / 分配承诺；控制器核对当前实际回收后才让资金合约封账。损失后资产保持风险锁；所有份额完成领取、无未分配余额，且治理批准恢复并有 holder 新同意后才可再次质押。无扣押 / 变卖的真实法律宣称。
- **B06**：带域的 `OfferingTerms` 与估值签名绑定 eBL、资产键、测试结算资产、净回收值、估值时间 / 有效期、coverage、供给、价格、目标兑付、到期 / 募集期限、exporter、费用和政策。发行时与认购时检查有效估值及最大风险敞口。经济条款不可变；重定价只允许降价且必须重新确认 quoteVersion。
- **B07**：治理为至少三名成员、两人同意、最低一小时等待；成员轮换使旧 epoch 队列失效。发行、估值、执行、资格、处置、guardian 分开授予；guardian 仅阻止新增操作，不能更改资金去向或阻止既有退款 / 领取。token 只绑定一次 pool，无法切换 minter。
- **B08**：受限教学测试，不宣称 KYC / AML 完成。资格以主体承诺、钱包、来源承诺、有效期、撤销和认证服务时效表示；未配置 / 服务失效 / 过期均禁止新认购。投资者必须对本池条款哈希和当前报价版本确认。资格撤销不剥夺退款 / 领取。
- **B09**：独立组织 / 主体 / 角色 / 钱包与服务端 capability 会话。会话只由已配置管理员签发，有效期、撤销、同组织授权；管理员 token 不自动授予业务发布权。关键发布要求两名不同主体审核；发布固定白名单投影，与私人材料分开保存。HTTP / SSE / MCP / A2A / 下载使用同一权限检查。现有旧端点不因此被宣称为企业身份体系。
- **B10**：新 Registry calldata / storage / event 仅含承诺、地址、计数和状态；不提交船、港、货物、原始提单号、身份材料、明文 CID。私人证据使用 AES-256-GCM 加密、随机 nonce、组织 / 记录 AAD、受控下载；公示仅为审核后的投影。密钥通过环境注入，不生成并留在数据旁，不回退管理员 token。已公开的旧链数据无法撤回。
